# Simple ls

## Project Description

A Simpleified version of the `ls` command that supports options `-a`, `-l`, `-R`, and sorting by modifiedd date/time

## Installation 

Step-by-step instructions on how to install and setup this project locally.

```
# clone the repository
git clone https://github.com/elijahnash4-droid/simple-ls-readme-submission.git

# Navigate to the project directory
cd ls-elijahnash4-droid
```

## Usage/Examples
To run the project input `./simple_ls` in the terminal.
